# 火影OL通用客户端

战斗防卡死默认开启：战斗画面连续3分钟无明显变化，或单场等待达到10分钟，会保存证据并中止该场等待。切换账号、背景动画和反复识别战斗标记不会重置单场上限。多账号模式在当前账号标签与战斗页面可确认时跳过卡住账号，继续其他账号；页面不明时停止。原场保留待处理，不自动重开或计胜，该账号本轮不自动托管。可在 `HYOL_Daily.ini` 中调整 `CombatStallSeconds=180` 和 `CombatMaxSeconds=600`；无效值使用默认值，单场上限最多20分钟。

打开游戏并登录要运行的账号，再启动完整客户端。支持当前窗口中1～6个稳定游戏标签；首次使用会自动注册账号身份，不需要填写角色名、区服或提供账号模板。身份资料和断点保存在当前Windows用户的`%LOCALAPPDATA%\HYOLClient\state`。

单人任务选择“当前账号”或“多个账号”，勾选所需任务后点击“开始 / 继续”。已完成的本轮任务会跳过；掉线账号会跳过并记录，脚本不会自动登录。

已有队伍选择“已有队伍 → 多人单人”，保留“自动发现当前队伍”。脚本从各账号本人头像的队长标记识别队长，核对成员后执行所选组队任务；完成后解散、核实无队和回村，再运行在线账号的单人任务。队员栏的队长标记不作为本人队长证据。

关闭程序、账号标签换序或重启游戏后，重新启动并点击继续即可按实际身份关联原断点。跨日恢复保留原已完成副本；历史未知结果只有在原会话已结束、当前身份和无战斗/结算页面连续确认后才隔离，历史结果仍为未知。当天未决结果会阻止重复操作。

F12或“立即停止”保存断点并暂停；只有点击恢复暂停才解除暂停。最后托管按选项执行，并核实当前任务、回村和托管状态。

干净发布包不包含任何账号名单、个人身份图、邀请人图、历史断点或本机状态路径。本地升级入口保留既有断点配置，不能把本地安装目录整体发送给其他用户；分享本工具生成的干净ZIP。

窗口、身份、活动入口或结果无法核实时，会显示具体待处理原因并保存证据。离线回归和构建通过只说明程序验证通过，游戏任务完成以当前实机记录为准。

版本：2026.10.11.1。

源码运行：Windows / Python 3.11+，创建 `.build-env` 后安装 requirements.txt，执行 hyol_client.py。

构建：运行 build_unified_client.ps1 或 build_team_client.ps1。

匿名专项测试：python -m unittest discover。随包不包含本机实机日志和历史账号资料。完整本地回归为 1064 项，结果见 ACCEPTANCE_REPORT.json。

本版增加战斗防卡死：默认画面连续180秒无明显变化或单场等待600秒即保存证据并中止等待。切换账号、动画及重复识别战斗标记不重置单场上限。当前标签与战斗页确认后跳过卡住账号，继续其他账号；画面不明时停止。未知原场不重开、不计胜、不自动托管。
