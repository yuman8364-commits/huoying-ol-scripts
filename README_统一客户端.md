# 火影OL 完整客户端

版本：2026.10.19.11。双击桌面完整客户端或多人脚本打开窗口，点击“开始”后才执行任务。

每次开始均使用当前勾选、当前账号及当前游戏画面创建新运行。停止或 F12 结束本轮；再次开始重新识别当前状态。界面不提供旧任务恢复、批次切换或历史任务浏览。

任务状态按运行单独保存，账号身份资料独立共享。历史日志、截图及旧状态文件保留在磁盘，不参与日常和多人流程的调度。当前每日次数和奖励状态从游戏页面核实，未确认的本轮操作不会重复提交。

单独“达摩”、周末（拼图＋达摩）和挖宝默认不勾选。单独达摩使用独立版引擎，只执行达摩，连续确认奖励为0并回村后才记完成；记录位于本轮state/runs目录，不读取独立EXE的历史断点。需要时手动选择，周末任务仍须处于活动开放时间。竞技场默认追加五胜；阵容默认保持不变；最后进入托管默认开启，可手动取消。

多人入口默认使用“已有队伍 → 多人单人”。请先在游戏内组队并准备队员自动战斗。开始时统一识别最多六个标签、账号及队长，只操作已核实队长执行所选副本、通缉和强者。强者只操作队长连续作战，直到队长奖励次数为0或画面连续确认体力不足；期间不切换队员检查自动战斗、结算或次数，也不会购买体力。

副本和强者先让两队进入本轮战斗，固定等待当前队结算，再切换另一队等待结算；两队都完成本轮后才开始下一轮。已参战队伍结果未知时保留待处理，其他队只完成当前场，不开始下一轮。

副本须核实今日奖励和友情奖励均归零，通缉须核实任务列表清空。每队完成后核验成员并解散，确认无队和木叶主界面，再执行勾选的单人任务及所选托管。开始前掉线或无法识别的整队本轮暂缓，其他已核实队伍及无队账号可继续。

启动进行一次完整账号识别。组队和单人阶段共享本轮映射，交接不重新扫描所有身份，当前已选标签不重复点击。标签布局变化最多重新绑定一次；无法确认身份或窗口会话改变时停止受影响操作，并显示本轮原因及截图。

“完成情况”只显示本轮账号与任务，点击单元格可查看结果、领奖、回村、次数及证据。新运行开始时清空上一轮显示。没有可执行账号时直接显示原因，不空跑后续环节。

短暂重绘采用有界重新采样。截图内重复判断共用识别结果，点击或切号后必须使用新截图。角色名被本轮战斗遮挡时允许观察战斗；内容操作仍须核实当前标签和页面。

托管沿用游戏当前设置，只执行入口、开始和托管中确认。挖宝只使用已有地图，每号独立计时五分钟，结束时核实暂停及回村。实际购买保持禁用。

独立羁绊保留其专用轮次与收尾规则，不属于本次多人任务恢复功能的替换范围。

离线回归、GUI启动及成品源码一致性分别核验；游戏完成须有当前运行的真实任务、结果、领奖和回村证据，活动未开放或跳过不会记作实机完成。
