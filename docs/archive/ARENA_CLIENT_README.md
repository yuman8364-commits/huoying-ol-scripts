# 火影OL竞技场独立客户端

版本：2026.10.17.8。保留完整程序文件夹，双击“火影OL竞技场通用v5.exe”打开界面，按当前高亮游戏标签执行。

每次点击“开始”按当前画面和本次胜场目标创建独立运行；停止或F12结束本轮。历史日志、截图与旧状态保留，不恢复旧日常任务，也不把历史胜场加入本轮目标。

默认阵容保持不变，竞技场追加5胜，可在界面调整目标。按当前战令状态选择可用模式；结果未知保持待处理，不推算胜场。

每场首次正向确认战斗页后，第二技能和自动各执行一次，然后观察结果。失败不计胜；任务完成须核实胜场、所选奖励、回村以及所选最后托管状态。

托管沿用游戏已有设置。掉线或无法核实当前标签、身份和页面时保存原因与截图，不自动登录或重复开战。购买保持禁用。

程序自带运行依赖，不需要另装Python或AI服务。离线回归和GUI启动通过不代表实机战斗或领奖已完成。
