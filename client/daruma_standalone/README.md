# 达摩独立版 2026.10.18.2

桌面双击“火影OL达摩”即可打开成品，也可进入“桌面/可用脚本/火影OL达摩”双击 `火影OL达摩独立版.exe`。成品包含Python运行库和所需素材；打开窗口后点击“开始 / 继续”才执行挑战。桌面成品的记录保存在EXE旁的 `runtime/`，更新时保留该目录。

双击根目录 `启动达摩独立版.cmd`，选择游戏窗口。先打开当前账号的达摩挑战页或周末福利达摩页，再点“只读识别”；确认页面后点“开始 / 继续”。“停止”或 F12 保存当前结果；再次开始时先核对原窗口、角色与未决动作。

源码启动仍使用项目 `.build-env`。构建成品运行 `build_daruma_client.ps1 -InstallDesktop`；每次输出到新的构建目录，并检查嵌入源码及素材后再安装。

这一版只处理当前账号的达摩挑战。每层根据实际图标增加和圆柱变化核实结果；有剩余机会和已核实奖励额度时，在结算页直接开始下一局。最后返回周末福利页，连续两帧核实奖励数字 0 和“已完成”后结束，停留在活动界面。局间估算不用于判定完成。当前局机会显示 0 时仍可完成本局；没有下一局机会时不会再次开始。

奖励栏被遮挡、数字不清或“已完成”未确认时，丢弃此前的稳定计数，重新观察。同一标签换角色或游戏进程不符时，原断点保持不变。每次开始/只读识别先清空界面旧计数；未识别的值显示“—”。已发送但结果未明的敲击不会重发；跨日未完成断点不自动重开。

所有运行资料都在本目录的 `runtime/runs/<运行编号>/`：`checkpoint.json`、`events.jsonl`、前后截图、`trace_*.npz`。只读观察和启动失败的资料在 `runtime/observations/`。不读写主脚本的任务记录、配置或人工暂停文件。

依赖项目已有 `.build-env`、只读视觉素材以及窗口/几何/互斥锁工具，不调用总调度器、周末组合流程或旧达摩执行入口。

命令行：

```powershell
.\.build-env\Scripts\python.exe .\daruma_standalone_gui.py --list-windows
.\.build-env\Scripts\python.exe .\daruma_standalone_gui.py --observe --hwnd 12345
.\.build-env\Scripts\python.exe .\daruma_standalone_gui.py --run --hwnd 12345 --strike-limit 1
.\.build-env\Scripts\python.exe -m unittest -q test_daruma_standalone test_hyol_daruma
```

`--strike-limit 1` 只发送一击，用于现场校准；独立窗口默认自动继续。截图耗时与游戏输入时延分别记录，输入时延采用最近三次独立实测的中位数，暂停后不会重复计入同一击。初始 150ms 只是待校准的估计。奖励栏被动画或公告遮住时只观察，恢复后重新采样；7秒仍不可靠则保存现场停止。
