# 火影 OL 桌面客户端 2026.10.24.3-local

本版沿用Kimi确认的界面设计，已接入原有Python任务运行层。双击“火影OL完整客户端.exe”后是实际客户端；点击“开始本轮”会执行当前选择的真实游戏任务。界面打开时不自动检查游戏或启动任务。

## 使用

1. 把ZIP完整解压到独立目录。包内有带版本号的外层目录，不覆盖旧版。
2. Windows 10/11 x64需已安装Microsoft Edge WebView2 Runtime及.NET Framework 4.8。本包使用系统WebView2，不捆绑完整浏览器引擎，也不要求用户安装Python或Node.js。
3. 双击“火影OL完整客户端.exe”，在任务计划选择账号范围、任务及参数。先打开游戏所需标签并准备好当前页面，再点击开始。
4. 在本轮进度查看账号、任务、待核实原因及图片证据；运行日志可搜索、筛选、导出。界面显示最近1000条，完整运行记录仍在原日志文件中。
5. 点击“停止本轮”或按F12。等待本轮结束后再关闭窗口。运行中点窗口关闭会保留窗口，并提示先停止。

账号掉线和整轮状态分开：其他账号仍执行时，整体保持执行中，停止入口保留。未核实、未开放和跳过不等于完成。完成状态来自原运行层的最终回执；数值为零或进度表看似齐全不能自行升级完成。

## 真实运行与界面演示

正常启动EXE接入实际任务控制器，不显示模拟状态切换器。需要只看界面时，运行同目录“查看界面演示.cmd”，或执行EXE的 `--demo` 参数；演示窗口会明确标注“界面演示数据”，按钮只推进演示，不连接游戏任务。

`--hidden --smoke-report <路径>`为开发者空闲启动验证参数，验证界面与桥接初始化后退出，不启动游戏任务。

标准版不包含ONNX运行库和模型，常规任务继续使用原模板识别；shadow诊断默认关闭。当前发布仅提供标准桌面成品，视觉诊断桌面包可用构建参数另行生成。

## 记录、配置与证据

- 原INI、任务参数及断点格式沿用2026.10.24.2-local。运行记录仍由原控制器及调度器保存。
- 账号身份、领奖、回村、未决动作、F12和购买禁用等规则继续由原运行层执行。本次没有改识别阈值、float64精度或任务执行顺序。
- 图片查看只接受本轮进度已记录、位于当前日志或本轮状态目录的PNG/JPG，不能从界面任意打开系统文件。
- “清空显示”仅清空当前显示范围，不删除日志。导出会在 `logs/exports` 生成最近界面日志的UTF-8副本。
- WebView通过Python原生桥接调用任务。只读资源服务仅提供界面静态文件，不提供HTTP任务控制接口。

## 从源码启动

在Windows PowerShell 7中使用Python 3.12创建环境，安装 `requirements-build.txt` 与 `requirements-desktop.txt` 后运行 `python -B hyol_desktop.py`。源码入口和EXE默认行为一致，会在点击开始后执行实际任务。

仅查看演示：`python -B hyol_desktop.py --demo`。

构建标准桌面版：`build_desktop_client.ps1 -PythonPath <环境中python.exe的绝对路径> -OutputRoot <新的输出目录>`。构建输出不能使用已有目录，以保留旧成品。需要可选诊断版时再安装 `requirements-vision.txt` 并增加 `-WithVision`。

## 验证边界

本轮执行原生桥接、原控制器相关专项、隔离替身交互及真实EXE的空闲启动验证。替身和固定回放只能验证接口及状态行为，不能代替真实游戏整轮、拼图子进程或长时内存验收。实机测试由用户自行执行，结果后续单独记录。本版本为本地交付，未自动上传GitHub。
